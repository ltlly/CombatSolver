# 初始生成与有限回复剪枝研究（2026-10-07）

本轮结论：有限回复可以用于已启动的精确Smart用药资格证明；在未修改原生行为的固定输入中，储君精英重复得到0战损，但没有稳定的速度收益。额外原生反例复现了“以后生成的牌有未登记OnPlay补丁，根仍取得有限证书”的认证缺口，**扩大认证的运行时代码和两个专属合同均撤回**。当前生产继续使用已验证的 `27c28f66`，没有部署实验DLL、提交新性能PR、合并或发布。

配套[结构化记录](initial-generation-finite-recovery-pruning-20261007.json)保留全部源码、失败准备、原生结果、三组纯对照、各次指标及清理记录。本文件属于研究证据，不表示全原版或未知扩展已认证安全。

## 更合理的证明边界

普通incumbent剪枝和Smart资格剪枝有不同前提。前者需要一条当前政策允许的完整可靠胜利，以及分支在所有剩余回复和其他目标下仍严格更差的证明；后者只能否证已经启动的精确用药层能否满足现有Smart门槛。普通终局比较有严格改善出口，不能把Smart门槛扩大成全局评分剪枝。

本轮原型复用 `StrategicHpRecoveryBound.ComponentHealingUpperBound` 和冻结独立库存证明。对非终局稳定分支，将已付成本、至少还需消耗的库存成本和额度内全部可能回复代入原Smart门槛；只有最好可能战损仍严格超过门槛时删除。相等、未知、挂起选择、风险、边界、成长、保命、显式遗物及资源追回不能由该消费者删掉。

最终原型补充了显式稳定P0资格：必须有动作、玩家存活、完整终局、无风险/边界、未用保命资源、实际无显式用药及已结束回合标记。仅 `Won=true` 的数值基线不能开启新消费者。旧零回复消费者、评分、普通比较、成员调度、搜索预算和原生效果保持原逻辑。

已生效再生与尚未使用再生药水分开处理。耗尽精确一瓶额度后，不能再计入第二瓶，但不能删掉已生效再生。多次使用、生成过滤、全部牌堆/消耗堆/待返回牌和永久来源继续沿既有保守查询，不另写治疗或药水语义。补药、同ID回填、免费来源和未知槽位状态不允许借用初始库存证明。

更紧的联合界需要按同一合法药水组合同时计算回复和成本，避免分别取“最大回复”和“最小成本”产生过松的界。已有[联合界数学研究](joint-recovery-cost-research-20261007.md)可复用；本根铁之心与再生药水成本均为9，联合化本身没有额外收紧，收益来自来源覆盖与已使用额度。

### 新增原生反例

`FUTURE-GENERATION-PATCH-AUDIT`，runId `4337f3cec02744cfa108c8965cf7c611`，25.845秒，Passed表示**反例复现**：

1. 确认源码类型 `SecretWeapon` 不在初始牌/永久牌组中，原生可战斗生成且属于当前解锁无色池。
2. 对其实际OnPlay安装一个未登记动态程序集前缀；现有 `AuditCardOnPlay` 直接检查该类型时抛出 `PredictionUnsupportedException`。
3. 同时捕获根却仍取得非空独立库存证书，分支回复上界仍为15。
4. `finally` 移除补丁；启动器清理独立 `.local` 实例，外层仍为120秒。

根的 `CaptureCardOnPlay` 只检查当前牌和已登记类型，源码注释也说明未来生成类型不在其覆盖内。生成池认证当前检查类型、原生过滤和正向名单，尚未检查这些类型的未来OnPlay补丁。没有打出这张带补丁的牌，也没有测得实际额外回复、错误终局或错误剪枝；已证明的是**未知来源被认证接纳**，不将它混同于暂停的丢路问题。

要将原型变成生产能力，应在主线程稳定根捕获可达生成/变牌/复制/回收集合的有效回调资格，递归形成闭包；任何未审计扩展拒绝认证。后台只读冻结证据及分支状态。无玩家回复证明、无药水/遗物获取证明和评分目标兼容证明分别成立后，才允许消费者使用，不能以一个证书替代另外两个。
