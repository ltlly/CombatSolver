## 改动与所有权

先核对真实源码：`ResetTurnCounter`已经跳过已有零值，空计数表通常按需创建；没有重复实现这些优化。新原型只涉及`ForkableCollections.cs`的字典Storage和两个int计数表指纹入口。

对一至四项的计数表，仍按原顺序枚举，逐项读取玩家／怪物身份getter及实际int值，再与Storage中不可变记录的全部输入逐项比较。只有输入完全一致才复用原来的两个无序贡献标量；marker及条目数仍进入原指纹。空表、null和超过四项的表继续原计算，显式零值、负值和全部比较规则保留。

缓存只持有四个标量输入槽、数量和贡献，不保存Model或callback，也不以集合哈希作为命中证明。各Fork仍拥有自己的字典wrapper；COW分离后使用新Storage，普通字典操作和枚举语义不变。共享Storage通过Volatile发布完整不可变记录，竞争写者只影响命中率。身份getter始终执行，未知getter的副作用和异常不得被缓存省略。本原型没有增加回复来源认证或剪枝。
