## 依赖仍需证明

有序卡牌指纹只覆盖已定义的局部语义。上下文会读全局费用、消耗关键词、牌型、标签及动态变量；未知getter、附着效果和扩展来源不能仅凭原版程序集身份放行。

现有镜像空集证书只排除相应回调参与者；它没有证明全部getter和生成闭包。部分动态变量有意归为派生字段，不能因为指纹相等就推断它们的基础值也相等。后续缓存必须补齐实际读依赖，保留当前列表顺序，并继续逐分支计算首击、回能、消耗抽牌和首领附加项。本轮没有实现整个上下文、Snapshot或Score缓存，也没有新增回复来源资格。
