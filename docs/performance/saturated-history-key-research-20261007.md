## 原生读取链排除了简单删计数

| 来源 | 实际读取 | 对候选的约束 |
|---|---|---|
| `Normality`（凡庸） | 本回合同玩家的开始出牌次数；合法性`<3`，显示变量`min(3,count)` | 单项门槛3已确认，尚不是全根证明 |
| `LethalityPower`（致命） | 攻击开始次数；在执行中门槛1，否则门槛0；重放另有当前play index条件 | 候选门槛2不能替代其他完整攻击历史 |
| `EvilEye`（邪眼） | `History.Entries.OfType<CardExhaustedEntry>().Any`，限定本回合/玩家 | 不能仅搜索`CardsExhausted` getter得出无其他读取 |
| `Midnight` | 进入战斗时对全部消耗历史`Count()`，不限定回合/玩家；消耗回调改变逐实例费用 | 全战斗消耗次数和费用依赖必须保留，未认证整体门槛化 |
| `JugglingPower`（杂耍） | 获得效果时读取完整攻击开始次数，第三次攻击复制卡牌 | 原完整攻击计数与私有prediction state仍须进入键 |
| `EchoFormPower` / `NostalgiaPower` | 首次序列、攻击/技能开始次数对任意Power层数的比较 | 不按固定常数截断 |
| `FeralPower` / `RingingPower` / `SmoggyPower` | 零费攻击、技能等不同历史谓词 | 不可互换为总出牌数 |

原生`CardPlaysStarted` getter有8处方法引用；泛型`Entries` getter另有24处，包含未来生成时的消费。定位清单只覆盖静态方法/委托引用，**不是字段访问、虚调用、回调或递归生成的完整认证**。本轮没有补全未知扩展闭包，不因原版程序集身份默认安全。

模拟侧`InitializeJugglingAfterApplied`读取另一个完整`GetAttacksPlayedThisTurn`计数，私有`JugglingPredictionState`亦已指纹化；二者保留。原键还包含完整序列计数、攻击/技能计数、有序牌堆、Power/费用状态、RNG等。局部可简化不代表完整键能合并。
