## 更合理的证明入口

后期能力计划启动前，协调器已经持有当前政策允许的完整获胜路线。追加搜索只在原比较器认定更优时替换它，否则保留该路线。新入口把这个事实与“精确用几瓶药”的专门审核区分：固定前缀和未来可能用药，并不阻止追加搜索与已保留胜利比较；精确用药层仍不能因此提前结束或替代反事实结果。

见证要求完整胜利、无风险/边界和保命资源消耗；消费者要求Smart、没有强制用药、整个有效成长HP额度向量为零、没有遗物或追回目标。分支使用已有严格组件回复证明，覆盖合法剩余药水、已有再生、战后及门槛回复，未知来源返回无限界。沿既有战略战损计算得到乐观下界，**只剪严格更差的HP**，相等战损继续寻找更便宜用药、更多成长和不同回合。胜负/保命/追回在HP之前的比较没有改动；后面的药水成本、成长计数和回合不能补偿严格更差的HP。

`RetainedPrimaryIncumbent` 是通过既有计划执行和continuation请求传递的不可变数值。完整胜利仍由调用者持有，后台只读取根与分支状态，不缓存跨Fork可变结果。当前只接入主搜索之后的能力计划；原先的无药见证、药水审计、评分、预算、排序和模拟语义保持原实现。先完成保路排名与事务再剪枝，避免提前过滤后回填弱分支改变转置竞争。

此前[胜利交接研究](late-plan-incumbent-research-20261006.md)针对旧严格认证无药入口，受内存失败撤回；本次不是重跑相同候选。它使用后来完成的独立逐来源证书覆盖零HP额度成长根，允许调用者保留的合规用药胜利，并只消费严格HP比较，没有GC改动。
