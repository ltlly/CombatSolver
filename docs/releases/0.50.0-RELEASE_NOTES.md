# CombatSolver 0.50.0

## 简体中文

- **特别感谢 [洛天琉璃依（ltlly）](https://github.com/ltlly) 提交的 [PR #207](https://github.com/Torch1230/CombatSolver/pull/207)！** 带来新一轮大幅性能优化，减少重复计算，让复杂战斗更快算出结果。与优化前的早期版本相比，代表战斗平均提速约 **2–3 倍**，部分复杂场景提速 **超过 30 倍**，重场景的内存占用也显著降低。同时改善用药选择，在相同战损下更好地保留省药路线。
- 感谢 [Fzhenhong](https://github.com/Fzhenhong) 提交的 [PR #211](https://github.com/Torch1230/CombatSolver/pull/211)：优化智能药水判断，让能明显降低战损的用药路线更容易被找到，并改善复杂战斗中的继续搜索。
- 修复智能药水策略在收益不足时仍继续搜索药水路线的问题，减少低战损战斗中不必要的计算等待。

## English

- **Special thanks to [ltlly](https://github.com/ltlly) for [PR #207](https://github.com/Torch1230/CombatSolver/pull/207)!** A major round of performance improvements reduces repeated work and solves complex battles faster. Compared with earlier versions before optimization, representative combat searches are around **2–3 times faster on average**, with some complex scenarios seeing **over 30× speedups**. Memory use in demanding battles is also substantially lower. Potion choices are improved, retaining routes that spend fewer potion resources for the same HP loss.
- [PR #211](https://github.com/Torch1230/CombatSolver/pull/211) by [Fzhenhong](https://github.com/Fzhenhong): Improved Smart potion decisions, making useful potion routes that save substantial HP easier to find, and improved continued searching in complex battles.
- Fixed Smart potion searches continuing when the potential benefit is too small, reducing unnecessary calculation time in low-loss battles.
