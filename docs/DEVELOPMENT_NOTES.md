## 未发布研究：重场景公共成本（2026-10-05）

当前任务分支合入上游 `4abef8c5`（v0.50.0，含 PR #207）；最新两条提交仅社区调查文档与skill，相对已验证的 `88e90001`，此前上游更新版本元数据与文档归档；既有运行时验证继续按原来源引用。后续仍以完整请求至少两倍、战损不增加、峰值内存至多增加10%为目标；已接受的感染棱柱与猎手精英例外不扩大到其他场景。

[选牌续接Fork锁等待](performance/continuation-fork-contention-research-20261005.md)严格解析7,481对等待事件，零丢失/未配对；手动续接各线程等待1,790ms不能当作可省请求时间。精确请求授权/并行读者/销毁排空原型完整机制合同通过，12次Evaluate交错保持根、导出质量及工作/剪枝，三根比值0.9851/1.0045/0.9673，没有稳定收益。原型及专属测试、架构、skill、门禁保存stash并撤回，未做整请求验收，沿用已验证部署。

[Fork与牌堆缓存研究](performance/fork-pile-cache-research-20261005.md)完成独立延后表、与投影/虚无组合、三类指纹COW三项原型；三次最小原生宿主合同通过，36次Evaluate交错保持根及导出质量/工作/剪枝，但未建立稳定通用收益，全部源码/测试/架构/skill/门禁保存研究stash并撤回。没有追加整请求验收或改变生产部署。复用完整分配解析后，SimCardPile类型只占确认搜索加权分配0.935%，不能把牌堆Fork全调用链当作可删除空间；下一阶段先量化既有通用续接的重复回放与拒绝来源。

[牌堆监听投影与虚无组合](performance/pile-listener-projections-20261005.md)完成原生八次完整差分、14来源拒绝、续接及DOP1/2/16核对；三根完整Coordinator交错及八根质量回归保持全部导出比较目标。大牌组整请求1.199倍/峰值−10.427%，储君0.972倍/峰值+11.156%，亡灵首领0.994倍；单对猎手精英与亡灵精英更慢。因内存门槛失败，组合源码及对应架构/门禁保存于研究stash `ff4eb7b5ff7560df423d6d9b1e79cc5f1c8ca58e`，未部署或提交运行时，沿用已验证上游同步源码及五文件部署。原两倍目标保留，后续Fork组合结果见上项研究，不重复原输入成功验证。

[共性成本分析](performance/heavy-scene-common-costs-20261005.md)复用七个已有整请求及同一份CPU/完整分配trace。近期五根主搜索用途仅占12%～27%；多成员、选择密度和牌组规模分别放大成本。细化Power复制子路径后，变量集合构造链仅占该采样分配3.062%，不以整个克隆阶段作为可删除收益。随后保持完整评估的中间状态类型原型构建、CARD-CONTINUATION-SEARCH通过；两根诊断的待选评估仅占全部快照累计时长2.414%／8.896%、worker分配0.299%／0.659%。没有启用延后评估，已保存补丁并撤回运行时和插桩；这些比率不是CPU或整请求提速。后续优先调查稳定候选的牌堆派生和模拟成本，复用既有认证、共享表及失效/Fork边界。

[公共状态派生研究](performance/derived-state-opportunities-20261005.md)新增396张牌CPU，Snapshot/Replay/Fork分别48.774%/31.591%/8.421%；包含投影洗牌14.207%，子路径不能相加。两个默认回调原型最小原生、完整状态/Fork/RNG/live及补丁刷新通过，16次Evaluate ACCA仅0.4%～1.7%差异，已撤回；保留ExtraTurn共享位oracle与AdvanceRound七参数测试修正。可选宿主诊断始终执行原投影；完整输入重复约1.9%/6.6%，排序依赖约1.9%/9.2%，不构建盲目整快照缓存，不称整请求提速。下一阶段优先降低每次排序/扫描与共同回放/复制成本。

[排序比较键研究](performance/native-sort-key-research-20261005.md)锁定同一原生模块及七个比较/读取补丁入口，603原版类型、363609对比较、40组排列/完整RNG及16并行Fork原生合同通过。结构体键两根交错更慢；改用分支wrapper的标量键直接原地排序，大牌组仅1.011倍/峰值+3.091%，储君0.994倍，未证明稳定通用收益。16次Evaluate全量记录、两份建局失败及最终修正保留；全部原型撤回，复用此前生产部署，整请求两倍目标继续保留。

[公共回放成本](performance/common-replay-state-cost-20261005.md)复用七根选中solver及同一396张牌CPU。已有卡牌／执行续接承担大量选择分支，进一步优先降低分支状态维护：五条监听路径采样并集18.713%，其中回放13.816、评估4.884个百分点。源码确认pending临时移除及wrapper拥有者，不能直接删锁或跨Fork共享可变对象；锁等待未测。按真实变更维护监听布局／评估依赖是后续方向，未新增运行时、游戏测试、提速验收或部署。
