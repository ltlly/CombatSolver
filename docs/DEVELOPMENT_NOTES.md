## 下一版本（开发中）

### Q002 能力与药水边界续搜（PR #213）

接入 [shun-tong](https://github.com/shun-tong) 的 [PR #213](https://github.com/Torch1230/CombatSolver/pull/213)：在现有组合成员及共享节点、时间预算内，从搜索自主生成的能力、用药和后续损血边界继续求解，改善长战斗路线。整合沿用 0.50.0 的组件回复证明、药水成本保护与智能开局药水准入。回放入口恢复完整搜索 profile 与录制开关，历史阶段见 [卷 21](archive/development/volume-21.md)，当前主线的同根质量及耗时证据见 [Q002 记录](issues/q002-route-quality.md#0500-主线整合2026-10-05)。

强制用药续搜按实际回合边界的完整回放状态准入：即使已生成路线在之后走到死亡，也可复用此前满足用药政策、仍存活的稳定边界。死亡、胜利和未完整应用的前缀由边界验证拒绝，`FIXED-PREFIX-TURN-OUTCOMES` 覆盖该合同及实机状态隔离。

2026-10-06当前性能任务分支[同步上游`9a4489d8`](performance/upstream-pr213-sync-20261006.md)：开发笔记冲突保留双方内容；Linux固定前缀与录制profile原生合同、能力估值及两平台职责门禁通过，Release零警告/错误，五文件本地部署完成。未追加整请求性能验收，既有失败原型保持撤回，旧数字不外推到新上游。

## 未发布研究：重场景公共成本（2026-10-05）

[指纹内联研究](performance/fingerprint-inline-research-20261006.md)确认洗牌热循环已经内联，仅尝试ulong混合的强制内联提示。12个编译方法IL一致、原生续接合同通过；12次短搜亡灵约1.021倍，但4次完整Coordinator仅1.0008倍，14项质量与工作/剪枝一致、内存通过。原型保存stash后撤回，运行时及部署复用当前上游源码；本轮fetch/merge没有新增上游提交，整体两倍目标保持。

[指纹关键词复用](performance/fingerprint-keyword-reuse-research-20261006.md)完成游戏/Ritsu调用链、根元数据权限与603卡/16标志原生合同；一次诊断省掉42,189次重复读取，认证约22毫秒。12次Evaluate大牌组约1.078倍、其他两根持平；4次完整Coordinator大牌组0.988倍，14项导出质量一致、内存门槛通过但无请求收益。源码及专属合同保存stash后撤回，部署复用上游合并版本；最新fetch/merge已是上游`9a4489d8`，没有新增正式提速成果或扩大例外。

[可选监听投影存储](performance/external-listener-projections-research-20261006.md)完成直接弱键表及存在位组合。三项原生机制合同与一项搜索helper、16次完整Coordinator保存全部结果；两根14项导出质量一致且内存门槛通过，但大牌组中位仅1.028／1.072倍、后版候选时间跨度较大，储君基本持平。两版源码／测试／架构／门禁保留研究stash并撤回，未追加最终七根及DOP验收，运行时和部署复用上游合并版本。

[原生牌堆查询与指纹关键词](performance/native-pile-lookup-opportunities-20261006.md)完成当前DLL三类定向阅读与三次可选Evaluate观察，227万查询大多数为空，Snapshot包含阶段约79%～87%；原生插入／移除使同一克隆的查询变化，live续用戳恢复。三个已有同输入控制的根、9项导出质量及工作量一致；完整比较质量为空。新增宿主pile-lookups模式，不永久缓存空结果；后续先证明指纹内诡诈／保留的关键词复用，未改生产部署或两倍目标。

[当前完整请求CPU与跨worker评估](performance/upstream-common-cpu-20261006.md)新增合入PR #213后的一次完整Coordinator采样和两次Evaluate诊断；评估/回放/Fork最近归因47.093%/31.628%/10.798%。新增宿主可选worker-families模式按实际lane拥有者计数：大牌组重复8.956%，亡灵受100,000键上限影响只得下限；同指纹/动作数存在历史偏移差异，未共享完整快照。生产源码及部署保持，原两倍目标继续。

[静态牌值公共缓存研究](performance/intrinsic-card-value-research-20261006.md)使用PR #213后的新基线，603类型/16Fork及严格增量合同通过，24次Evaluate与24次完整Coordinator保留逐次结果。三根交错大牌组约1.047倍、亡灵首领约1.022倍，最终九根全部14项导出质量一致；固定猎手精英/亡灵精英峰值+74.897%/+81.153%，部分请求更慢。原型、专属测试及架构/skill/门禁保存研究stash并撤回；运行时及五文件部署复用已验证上游合并版本，未新增正式提速成果。

[稀疏回调位置与窗口研究](performance/sparse-hook-positions-research-20261006.md)完成六次原生请求、36次Evaluate及14次完整Coordinator。首版大牌组约1.043倍但峰值+12.673%超门槛；逐回调缓存未证明收益，缩小窗口组合更慢且峰值基本不变。亡灵控制第二次未获胜，聚合比值不作同质量验收。三版源码/测试/架构/skill/门禁保存stash并撤回，运行时未纳入正式成果。

本节研究以合入上游 `4abef8c5` 的源码为基线（v0.50.0，含 PR #207）；研究数字仅适用于各报告列出的输入与产物。当前上游同步至 `9a4489d8`（含 PR #213），其运行时变化需独立验证，不沿用旧性能结论。后续仍以完整请求至少两倍、战损不增加、峰值内存至多增加10%为目标；已接受的感染棱柱与猎手精英例外不扩大到其他场景。

[选牌续接Fork锁等待](performance/continuation-fork-contention-research-20261005.md)严格解析7,481对等待事件，零丢失/未配对；手动续接各线程等待1,790ms不能当作可省请求时间。精确请求授权/并行读者/销毁排空原型完整机制合同通过，12次Evaluate交错保持根、导出质量及工作/剪枝，三根比值0.9851/1.0045/0.9673，没有稳定收益。原型及专属测试、架构、skill、门禁保存stash并撤回，未做整请求验收，沿用已验证部署。

[Fork与牌堆缓存研究](performance/fork-pile-cache-research-20261005.md)完成独立延后表、与投影/虚无组合、三类指纹COW三项原型；三次最小原生宿主合同通过，36次Evaluate交错保持根及导出质量/工作/剪枝，但未建立稳定通用收益，全部源码/测试/架构/skill/门禁保存研究stash并撤回。没有追加整请求验收或改变生产部署。复用完整分配解析后，SimCardPile类型只占确认搜索加权分配0.935%，不能把牌堆Fork全调用链当作可删除空间；下一阶段先量化既有通用续接的重复回放与拒绝来源。

[牌堆监听投影与虚无组合](performance/pile-listener-projections-20261005.md)完成原生八次完整差分、14来源拒绝、续接及DOP1/2/16核对；三根完整Coordinator交错及八根质量回归保持全部导出比较目标。大牌组整请求1.199倍/峰值−10.427%，储君0.972倍/峰值+11.156%，亡灵首领0.994倍；单对猎手精英与亡灵精英更慢。因内存门槛失败，组合源码及对应架构/门禁保存于研究stash `ff4eb7b5ff7560df423d6d9b1e79cc5f1c8ca58e`，未部署或提交运行时，沿用已验证上游同步源码及五文件部署。原两倍目标保留，后续Fork组合结果见上项研究，不重复原输入成功验证。

[共性成本分析](performance/heavy-scene-common-costs-20261005.md)复用七个已有整请求及同一份CPU/完整分配trace。近期五根主搜索用途仅占12%～27%；多成员、选择密度和牌组规模分别放大成本。细化Power复制子路径后，变量集合构造链仅占该采样分配3.062%，不以整个克隆阶段作为可删除收益。随后保持完整评估的中间状态类型原型构建、CARD-CONTINUATION-SEARCH通过；两根诊断的待选评估仅占全部快照累计时长2.414%／8.896%、worker分配0.299%／0.659%。没有启用延后评估，已保存补丁并撤回运行时和插桩；这些比率不是CPU或整请求提速。后续优先调查稳定候选的牌堆派生和模拟成本，复用既有认证、共享表及失效/Fork边界。

[公共状态派生研究](performance/derived-state-opportunities-20261005.md)新增396张牌CPU，Snapshot/Replay/Fork分别48.774%/31.591%/8.421%；包含投影洗牌14.207%，子路径不能相加。两个默认回调原型最小原生、完整状态/Fork/RNG/live及补丁刷新通过，16次Evaluate ACCA仅0.4%～1.7%差异，已撤回；保留ExtraTurn共享位oracle与AdvanceRound七参数测试修正。可选宿主诊断始终执行原投影；完整输入重复约1.9%/6.6%，排序依赖约1.9%/9.2%，不构建盲目整快照缓存，不称整请求提速。下一阶段优先降低每次排序/扫描与共同回放/复制成本。

[排序比较键研究](performance/native-sort-key-research-20261005.md)锁定同一原生模块及七个比较/读取补丁入口，603原版类型、363609对比较、40组排列/完整RNG及16并行Fork原生合同通过。结构体键两根交错更慢；改用分支wrapper的标量键直接原地排序，大牌组仅1.011倍/峰值+3.091%，储君0.994倍，未证明稳定通用收益。16次Evaluate全量记录、两份建局失败及最终修正保留；全部原型撤回，复用此前生产部署，整请求两倍目标继续保留。

[公共回放成本](performance/common-replay-state-cost-20261005.md)复用七根选中solver及同一396张牌CPU。已有卡牌／执行续接承担大量选择分支，进一步优先降低分支状态维护：五条监听路径采样并集18.713%，其中回放13.816、评估4.884个百分点。源码确认pending临时移除及wrapper拥有者，不能直接删锁或跨Fork共享可变对象；锁等待未测。按真实变更维护监听布局／评估依赖是后续方向，未新增运行时、游戏测试、提速验收或部署。
